# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-XX

### Added
- Initial release of Glimpse Restaurant Management System
- Role-based authentication (Customer, Admin, Waiter)
- Luxury restaurant website with home, about, menu, reservation, and contact pages
- Visual table reservation system with real-time status
- Menu management with search and category filtering
- Customer ordering system with tax calculation
- Admin dashboard with statistics and waiter approval workflow
- Waiter dashboard for order management
- Email notifications for key events
- Image upload support for menu and gallery
- MySQL database with complete schema
- JWT-based authentication
- Nodemailer integration for email services

### Features
- Customer self-registration
- Waiter self-registration with admin approval
- Reservation approval/rejection by admin
- Order status tracking
- Profile management
- Password change functionality
- Responsive design with Tailwind CSS
- Smooth animations with Framer Motion
