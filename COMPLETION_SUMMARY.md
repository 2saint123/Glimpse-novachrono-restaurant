## 🚀 How to Use

### 1. Setup Database (5 minutes)
```bash
mysql -u root -p < ENHANCED_DATABASE_SCHEMA.sql
```

### 2. Install Dependencies (2 minutes)
```bash
cd backend
npm install
```

### 3. Configure Environment (3 minutes)
Edit `backend/.env`:
```env
DB_PASSWORD=your_mysql_password
MAIL_USER=your_email@gmail.com
MAIL_APP_PASSWORD=your_app_password
```

### 4. Start Server (1 minute)
```bash
npm run dev
# Or use: start-backend.bat
```

### 5. Test with Postman (10 minutes)
- Import `Glimpse_Restaurant_API.postman_collection.json`
- Login as admin
- Test all endpoints

**Total Setup Time: ~20 minutes**
